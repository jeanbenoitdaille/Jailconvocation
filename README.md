# Jailconvocation

Exercice JavaScript de génération d’un texte de convocation à partir de valeurs saisies par l’utilisateur.

## Objectif pédagogique

Manipuler :

- `prompt()` ;
- les template literals ;
- l’interpolation `${...}` ;
- `toUpperCase()` ;
- la construction d’un texte multi-lignes ;
- `console.log()`.

## Fonctionnement

Le script demande un motif, un nom, un prénom, une civilité, une date et un numéro de bureau, puis construit et affiche une convocation textuelle.

## Limites historiques

Il s’agit uniquement d’un exercice de génération de chaîne. Aucune donnée n’est validée, enregistrée ou envoyée, et le texte produit n’a aucune valeur administrative ou juridique.

Le script utilise `prompt()` et nécessite donc un environnement navigateur ou équivalent.
